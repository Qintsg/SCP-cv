# 前端体验中的状态表达

## 坑132 — 配置开关不代表资源已经执行（2026-10-15）

- 症状：上传文件还没选择，预热开关却显示“已预热”；编辑页也把preheat_enabled配置写成完成状态。
- 根因：用户可见文字描述了执行结果，而字段只决定播放器下次启动时是否预热。
- 检出：本机真实浏览器打开上传抽屉即可看到；新增文案回归先以“已预热”失败，再验证上传/编辑均为“启用预热”。
- 现状：只改提示，不改变预热、播放或接口语义。声音来源仍明确显示最后发送请求，实际来源须现场确认；在线、受理和播放中也分别展示。

页头重构另发现两个不同问题：设置连接端口摘要被删除是真回归，现已恢复；旧标题类名被替换导致六项导航测试失败，改为检查唯一的语义标题后，原窗口/零写入断言保持。不能把这两类失败都称为测试误判。详见[013记录](../../specs/013-frontend-experience/verification.md)。

## 坑133 — 空字段和错误投影不能证明部署前后相同（2026-10-15）

- 症状：自有部署脚本读错播放代次字段，前后会同时为null；清单比较未指定`-Property *`又把未排除的网页字段当作后端配置变化。
- 根因：核验代码没有对照正式SessionSnapshot，且误用PowerShell投影参数，不是播放器或配置实际变化。
- 检出：实际输出出现null后，对照API类型定位字段；增加代次非空/相等断言，以新基线重验。清单先逐属性定位，再用正确的排除投影复核。
- 现状：旧失败脚本和结果保留，修正核验后确认真实1107/772代次、原七身份和非网页配置不变；不改生产状态迎合测试，详见[部署记录](../../specs/013-frontend-experience/deployment.md)。
