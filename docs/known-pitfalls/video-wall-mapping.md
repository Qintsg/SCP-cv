# 大屏映射接入的边界（2026-10-09）

- **重复输入覆盖**：输入地址不是墙面窗口ID。`1|1`、`IP81|IP81`需两组独立Sign/Level；不启动第三播放器。
- **屏号/裁剪混用**：IP按列优先且146/147互换，C按行优先，B每窗累计；逐片核对位置和尺寸，旧400包保持。
- **假成功/重启**：TCP写出不等于出画。草稿、上次发送意图、发送状态分离；失败/取消/提交异常报不确定，发送中重启不自动重发。数据库不可写时保留原失败，不称状态恢复。
- **版本校验**：先检查JSON ValueKind，再TryGetInt64，避免字符串/null/数组导致500。无效版本400且不发包，旧版本409；表单编辑后禁用应用。
- **回读冒充ACK**：6102仅N22按窗口解析；半包/粘包/噪声/加密有界处理。缺可信查询触发和操作关联，诊断不是实体确认。
- **验证污染**：全套与追加测试同时编译同项目，产生DLL/Manifest锁和5项失败；须停止交叉编译后串行重跑，不放宽断言或冒称实体通过。

定位见[009验证](../../specs/009-wall-input-mapping/verification.md)和[运行指南](../video-wall-mapping.md)。历史坑21的门禁由009在受限三输入组合内接续，未登记IP/未知几何仍拒绝。
