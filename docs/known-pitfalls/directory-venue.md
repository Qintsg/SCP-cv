# 目录与现场控制台记录

## 坑100 — 输入节点换成1080P后仍按4K裁剪

- 症状：墙面显示局部放大、重复窗口或黑片，发送成功不代表裁剪正确。
- 原因：63/64当前输入1080P，却沿用历史4K源尺寸。不能让同样依赖默认值的测试自证。
- 检出与修复：独立断言12种组合源边界与覆盖，63/64默认1920×1080；81保留独立尺寸。旧55/56 golden显式绑定旧4K配置，黄金字节不改。
- 边界：本机裁剪回归与新包部署通过；用户此前“现在正常了”的现场确认属于旧临时发送，不当作012所有组合实测。

## 坑101 — 内置目录只隐藏前端菜单或按名称判定

- 风险：直接HTTP、移动/上传或父目录操作可绕过页面限制；普通用户同名目录可能被静默收编。
- 修复：可信SystemKey标记与祖先链检查覆盖所有写入口；同步Camera幂等。遇用户已有同名目录拒绝收编并记录，不破坏旧数据。公开路径取实际保存叶名，重名不覆盖；旧存量原件不强行重排。
- 验证：服务/HTTP保护与真实六路目录界面通过；移动/删除按逐项结果，不把请求受理当实际播出。

## 坑102 — 切墙成功后音量失败被当作整体成功或整组重试

- 风险：画面已经发出，若声音阶段失败后重放墙面，会制造第二次实体副作用。旧程序音频帧可以编码，不表示已确认实际通道。
- 修复：成功切墙后屏幕音量最多一次配置；首次先读取实际值。写后读回失败/不一致独立报告，禁止自动重试；未知高级绑定在所有副作用之前拒绝。现场音量与电脑系统音量分离。
- 验证：次数、失败阶段、预设单项/空项和缺绑定零写回归通过；D4实际读100/同值写后读100。话筒、来源及扬声器可听仍未完成。

## 坑103 — DOM用例通过但真实输入标签/测试进程归属不正确

- 症状：真实浏览器按标签无法找到Naive内部输入/禁用复选框；Windows服务包装进程退出后子进程仍占夹具端口，下一轮复用了旧数据库/账号。
- 修复：ARIA传给实际输入，保护选择器显式标禁用语义；独立随机DataRoot，启动前拒绝占用端口，结束仅核对精确夹具命令归属后关闭子进程。截图等抽屉关闭和刷新完成，再核实际几何。
- 验证：最终456前端回归、独立真实浏览器完整目录/预设流程和390px四页通过；原失败保留。不通过改变生产期限、默默复用服务或隐藏溢出来变绿。
