# HTTP默认HTTPS入口

## 坑137 — 跳转须发生在业务处理之前（2026-10-15）

- 症状：只改首页脚本或页面链接，深层地址、API与HEAD/POST仍可能先按HTTP执行。
- 根因：页面导航层不能替代网页服务的所有请求入口，HTTP上游也不应先收到业务再返回跳转。
- 检出：真实HTTP监听统计下游调用，检查307、同主机实际HTTPS端口、原路径/查询、no-store；另外检查HTTPS分支无循环和无TLS开发。
- 现状：跳转位于公共middleware前部；55项相关回归通过。原协议会话兼容机制保留，HTTPS证书正常验证，不用永久缓存或关闭TLS掩盖配置变化。
