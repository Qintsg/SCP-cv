# 4K与现场控制工作区（016）

本轮仅在本机开发和验证，**尚未推送或部署D4**。不操作现场墙面、电源、云台、声卡或Windows显示设置。

## 大屏布局与窗口

- 仪表盘提供单屏、双屏、自定义。单/双屏的来源选择在画面上方，预览区域32:9；选完点击一次“应用布局”，内部仍保留修订检查，不需要额外保存草稿。
- 自定义是10列×5行。拖选空矩形后点“选择窗口”，指定来源；已占用块不能再被框选覆盖，点击块可换源或删除。键盘用Shift+方向键扩展、Enter选源、Esc取消。
- 窗口1/2仍是D4输入63/64，IP81仍为笔记本输入。截图一处IP84按已确认现场关系保留为IP81，摄像机绑定未更改。
- 窗口3/4是D4后两路输出的前端预留，不创建.NET播放器，不猜测65/66。可纳入规划和代码，但实体应用明确拒绝；对应页面只显示预留说明。
- 自定义IP指已登记的设备输入IPv4，不是任意RTSP播放地址；任意直播源仍在媒体库中登记后打开到窗口1/2。

### 布局代码

右上角代码实时匹配当前布局，输入后“读取代码”只还原本地编辑态，**不自动切墙**。代码v1由版本/块数、稳定排序的矩形、输入/IPv4和CRC16组成，使用大小写敏感Base62，不依赖数据库或查找表，不含凭据。相同内容不同编辑顺序得到同一码。

窗口1全屏示例`1IHdoxVLz`；窗口1左窗口2右示例`1TVQvzf6NxUXc`。常见1–4块约9–30字符；密集、多独立IP布局会更长，最多480字符，不做有损截断。非法字符/版本/损坏/重叠/越界整体拒绝，不部分替换。

### 4K与协议安全边界

63/64源尺寸默认改为3840×2160；IP81保留1920×1080，50个墙面节点的目标尺寸仍1920×1080。原生窗口按实际显示器物理像素定位，PDF按目标像素渲染，不再把默认低分辨率栅格放大。

**用户需自行修改D4 Windows两块输出分辨率，并确认编码器实际输入/码流同步为4K，再进行现场画面验收。** 软件配置不能证明编码器已切4K。

整块屏幕对齐的矩形使用既有PacketCodec和清屏→映射→提交→刷新链。源裁切必须满足宽度能被“列跨度×4”整除、高度能被“行跨度×4”整除，否则可编辑/预览/保存但禁止实体应用。4K的7/9列跨度、IP81的4行跨度等仍待余数协议独立证据，不擅自四舍五入发送。146/147节点交换与已有每节点顺序保持。首页每次应用仍发送当前现场音量配置。

## 直播预览（已由018替代本机桥）

当前实现改为现有MediaMTX按需共享上游、服务器FFmpeg转HTTP-FLV／WS-FLV，观看电脑无需Node／FFmpeg。没有人观看就释放，不按客户端重复拉同一实际流；拥塞时降输出码率／帧率，默认低清优先。详见[018使用／配置／网络边界](stream-preview-018.md)。

用户在018明确允许经D4转发，替代016原本“必须用户本机直拉”的限制。旧本机桥及令牌入口已删除，Git历史可恢复，不再要求安装loopback工具。此代码尚未部署，不能把本机合成流成功当作现场设备可用证明。

控制D4和普通浏览器兼容的视频本来就不需要访问端安装Node／FFmpeg；浏览器不能直接连接原始RTSP／RTMP，换Vue播放器本身不能消除协议转换层。

## 媒体与预案

媒体目录与文件同表显示，播放状态独立一列，不重复显示文件路径。搜索、类型筛选、保护目录、批量移动/删除和“打开到…”继续保留。摄像机内置目录仍只读。

预案同样使用目录列表，并有明确“编辑”入口。目录可输入已有路径并联想；新路径请先在列表创建目录。新预案默认窗口1全屏，可选窗口1左窗口2右或高级编排。高级编辑器有独立工作副本，取消不改变预案，保存对应布局码，编辑阶段不发设备命令。旧预案的“不改变布局”仍保留，不能静默改成切墙。

摄像机机位0或留空为保持，1–6为调用位置；音量为百分比，**0就是0%，只有留空保持**。现场高级参数“全部保持”不清除已经设置的大屏布局码。

### YAML文件

Host在`<DataRoot>/scenarios/<用户目录>/<预案名称>.yaml`保存完整预案快照，SQLite保留检索/执行索引。高级代码位于`advanced.wall_layout_code`，没有短码查找表。

新建、编辑、移动、目录改名、置顶和删除都同步YAML。数据库提交前只写私有暂存文件；准备失败回滚索引，提交后逐文件原子发布。若发布或提交回执不确定，接口明确失败，不宣称全部保存、不自动重试。移动只删除已跟踪且身份匹配的旧文件，不递归清空用户目录，不覆盖身份不符的文件或符号链接。

调用前核对同一快照的YAML与索引；文件缺失或不一致时拒绝实体动作。旧版本预案首次需要在网页编辑并保存一次以生成YAML（保存时会为当前所有索引项生成文件）；勿在运行中直接手改YAML，暂不提供外部YAML导入。旧头戴/悬挂别名和机位0/null按同一意图比较，不把无影响的别名差异当作配置变化。

## 页面与维护

背景音乐页收紧为播放台与内滚动列表，桌面常规高度无整页滚动；小屏保留整页自然滚动和44px触控目标。移除装饰性波形/唱片，避免挤压操作。

侧栏采用用户指定SSPU AILAB原PNG，设置下沉，去掉多余说明。设置运行态只放维护入口、控制连接与本机预览，运行组重启和窗口重置必须确认；“重启运行组”不是重启Windows。开发诊断改为宽卡片，静态依赖检查不代表原生放映已验证。
