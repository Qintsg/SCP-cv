# SCP-cv 使用文档

SCP-cv 控制上海第二工业大学 28#108 的大屏、电视、摄像机和现场声音。控制台提供网页、Windows 和 Android 客户端；播放服务运行在 Windows 交互桌面。

## 连接与登录

在现场访问[控制台](https://192.168.5.194/)。HTTP 入口会跳转到 HTTPS；屏幕共享需要浏览器信任的 HTTPS 连接。Windows 和 Android 客户端首次使用时，在“连接播放主机”中保存地址，再登录。

连接状态表示控制台与服务的连接；窗口卡片中的播放器状态表示播放进程是否在线。修改密码后，若页面提示会话尚未同步，点击“重新同步会话”。退出时若提示服务器退出尚未确认，请恢复连接后再次退出或联系管理员。

## 仪表盘

窗口 1、2 对应 D4 的两路播放器，窗口 3、4 提供预览。点击窗口卡片进入相应控制页。

在“大屏布局”中选择单屏、双屏或自定义，再选择输入并点击“应用布局”。单屏显示一路，双屏分别选择左右输入；自定义模式可在 10 列、5 行网格上选择矩形区域并配置来源。布局代码可复制或输入，用于分享同一布局。输入选项包括窗口、IP81、工作站、摄像机和已登记的设备流。控制帧发送后，请以现场画面确认结果；失败时先核对墙面与日志。

仪表盘右侧提供系统音量、拼接屏电源、电视电源和电视内容选择。电视电源使用切换指令，操作前请确认现场状态；电视显示内容可分别选择一路输入。拼接屏关机指令分两次发送，间隔 5 秒。

## 媒体源

媒体和文件夹按目录浏览，路径以 `/` 开头。可以搜索、筛选、上传、移动和删除，也可以点击“打开到…”选择窗口 1 或窗口 2。媒体库上传进入当前目录；在窗口选源界面上传时进入根目录。

上传文件保存在播放主机的 `DataRoot/media/`，例如 `media/PPT文件/b.pptx`。同名文件自动追加序号。上传上限为 1 GiB，包含表单与传输开销；代理或 IIS 还需配置相应限制。本机路径属于播放主机。

删除或移动播放中、转换中、被占用或只读的原件前，请先停止相关任务。删除文件夹默认将其媒体移到根目录；选择“同时删除内容”会永久删除目录和其中的媒体。遇到 `media_cleanup_pending` 时，请按维护提示检查隔离清单。

### 直播流

在“媒体源 → 上传或添加 → 直播流”填写地址，保存后选择窗口打开。RTSP、RTMP 和 HTTP(S) 地址可以包含凭据，例如 `rtsp://用户名:密码@主机:端口/路径`。用户名或密码中的 `@`、`#`、`:`、`%` 等特殊字符需要百分号编码，例如 `@` 写成 `%40`。SRT 使用自身参数；UDP/RTP 不支持地址中的用户名和密码。

地址修改在下次打开时生效。播放摘要和自动名称隐藏凭据；授权媒体配置保存完整地址，请保护配置和数据目录。

`/Camera` 包含五路摄像机和固定监控，系统目录及其来源不可编辑或删除。摄像机为 84–88，固定监控为 76。工作站目录列出可连接的工作站输入。

### 网页与演示文稿

网页由播放器打开；网页内的音视频可能需要在页面上点击播放。PPT/PPTX 使用 LibreOffice 动态播放，原文件保留。静态页图和 PDF 在后台准备，准备完成后可在打开时选择；文字适配默认为关闭。PDF 文件直接作为 PDF 播放。

文稿使用“上一步”“下一步”控制动画；PDF 和静态页图按页切换。专注模式中，方向键和 PageUp/PageDown 与这两个按钮对应，桌面可点击缩略图定位页面。最后一页的动画结束后，再按下一步会提示已是最后一页。指令状态和页码由播放器报告。文稿格式、动态播放限制及依赖配置见[文稿运行指南](libreoffice-playback.md)。

手机控制台使用悬浮底部导航，保留播放、选源、布局、摄像机和音量控制。手机横竖屏均停止加载实时预览、文稿图片和媒体缩略图；文稿专注页提供页码、备注与两颗步进按钮。底部操作避开系统手势区域。

## 屏幕共享

在桌面浏览器的窗口控制页展开“屏幕共享”，点击“选择共享内容”，选择屏幕、应用窗口或标签页。需要共享内容声音时，先勾选内容音频，画面和音轨可用后再开启声音。手机控制页不显示共享发起入口。

共享画面为临时内容，不保存到媒体库或预案。停止后若显示“停止待确认”，可查询停止状态；共享释放后可重新选择内容。详细配置见[屏幕共享文档](screen-sharing.md)。

## 摄像机与现场声音

在“摄像机与音量”页面选择摄像机并查看预览。按住方向或变焦按钮控制云台，松开按钮结束运动；可保存和调用 1–6 号预置位置。保存位置会覆盖该编号原有位置。

现场音量支持电脑、手持话筒和悬挂（头戴）话筒。声音来源可选择 IP81 或 SCP-cv，选择后点击应用。大屏音量提供设备读回；话筒音量和声音来源显示发送结果，实际效果以现场设备为准。切换大屏布局后，系统会发送当前大屏音量配置。

## 背景音乐与预案

背景音乐由独立播放器输出，支持播放列表、进度定位、循环、音量和静音。播放状态与进度以播放器回报为准；停止、加载或时长未知时无法定位。

预案按目录管理，可新建、编辑、移动、删除和调用。窗口可选择保持、黑屏或指定媒体；高级设置可指定摄像机预置位置、声音来源与音量。未填写的高级项保持当前状态。屏幕共享为临时内容，生成预案前请停止共享或切换固定源。

预案调用可能操作大屏、电视、音量和摄像机。若界面报告部分操作失败，请先核对现场状态，再决定如何处理。

## 环境与启动

播放主机需要 Windows 10/11 x64、.NET SDK 及 .NET Framework 4.8 运行环境、Node.js、LibreOffice、VLC/libVLC 和 MediaMTX。依赖安装与构建命令见[README](../README.md)。网页预览由播放主机按需转换；Electron 客户端使用随包组件读取直播流。

D4 可使用桌面上的 `SCP-cv 一键启动.cmd`。开发环境可在 PowerShell 7 的交互桌面启动播放服务：

```powershell
pwsh -NoProfile -File runtime-dotnet/scripts/run-headless.ps1 `
  -SafetyMode Hardware `
  -StartWorkers `
  -Detach `
  -DataRoot data/dotnet `
  -ListenUrls https://localhost:18443 `
  -AllowedHosts 'localhost;127.0.0.1' `
  -AllowedOrigins 'https://localhost' `
  -DevelopmentPasswordFile '<口令文件>'
```

停止运行组：

```powershell
pwsh -NoProfile -File runtime-dotnet/scripts/run-headless.ps1 `
  -Stop -DataRoot data/dotnet
```

播放窗口需要登录用户的交互桌面。启动配置、证书、音频端点和显示器绑定见[维护文档](维护文档.md)。

## 常见问题

- **控制台无法连接**：检查播放主机地址、网络、证书信任、服务监听地址和防火墙；恢复连接后可重新检查。
- **播放器离线**：检查交互桌面、ControlHost 与 Supervisor 日志、播放器进程和 Named Pipe 连接。
- **文稿无法播放**：检查 LibreOffice 依赖与文稿状态；页图缺失时可重新准备。资源释放状态为 `uncertain` 时，先检查文稿进程和日志。
- **直播无法播放**：检查直播源地址、凭据、网络和播放器错误；使用 MediaMTX 时检查其服务和端口。
- **拼接屏内容未变化**：检查输入流实际分辨率、50 个节点的连接与视频墙日志。电源控制和画面映射分别使用独立设备链路。

接口说明见 [OpenAPI](openapi.yaml)，现场设备及输入说明见[大屏映射指南](video-wall-mapping.md)和[设备操作指南](web-access.md)。
