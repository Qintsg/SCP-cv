# 大屏输入组合与协议接入

大屏布局可选择单屏、双屏或自定义网格。输入尺寸及设备回读见[输入分辨率维护](input-resolution-021.md)。

## 输入与组合

播放器仍只有窗口1/2，控制桌面不占用；重复映射不会新增播放器。笔记本绑定现场“输入IP81”，不是控制电脑的任意网卡。

| 控制台输入 | 单播地址 | 组播地址 | 组播端口 | 当前源尺寸 |
| --- | --- | --- | --- | --- |
| D4 窗口1 | 192.168.5.63 | 224.1.1.63 | 5000 | 3840×2160 |
| D4 窗口2 | 192.168.5.64 | 224.1.1.64 | 5000 | 3840×2160 |
| 笔记本 / 输入IP81 | 192.168.5.81 | 224.1.1.81 | 5000 | 1920×1080 |

63/64 在 2026-10-23 的主组播回读为 4K；IP81 为 1080P。切换输入前应核对实际主组播尺寸与配置。

支持3个全屏：`1`、`2`、`IP81`；9个左右组合：`1|2`、`2|1`、`1|1`、`2|2`、`IP81|1`、`IP81|2`、`1|IP81`、`2|IP81`、`IP81|IP81`。左右各自还可选择“不映射”，仅留一侧；不能两侧同时为空。

在仪表盘选择“单屏”“双屏”或“自定义”，配置输入后点击“应用布局”。双屏左右可选择同一输入；自定义模式按矩形选择10×5网格，并可使用布局代码。工作站和摄像机可从“其他输入”选择。预览按需连接对应视频流。

应用时服务先预检配置并发送对应修订；冲突返回错误。普通完整布局200包，单侧175包，Type3完整布局250包。

旧D2的55/56不再是当前默认输入。历史兼容测试仍使用显式55/56配置验证两预设合计400个黄金样本，不能据此把历史地址填回D4或声称D4数据包与旧样本逐字节相同。

窗口1/2标记逻辑输入。预案可保存固定或自定义布局；不设置大屏布局时保持现场画面。

## 状态不是出画证明

| 状态 | 含义 |
| --- | --- |
| `none` | 尚无本版本发送记录，历史模式不充当新协议验收 |
| `dispatching` | 正在发送，实体画面未确认 |
| `simulated` | 模拟应用，未给实体节点发包 |
| `sent_unconfirmed` | 控制帧写出完成，无关联本次操作的设备确认 |
| `uncertain` | 中途失败、取消、提交异常或发送中重启，可能有部分副作用 |

发送失败时请检查现场画面与日志，再决定下一步操作。重启会将中断的`dispatching`标为`uncertain`，不会自动重发。IP81自身声音由现场音源控制。

## 协议配置

ControlHost的`VideoWall`已登记63/64/81三输入。默认`SendType=1`、`CutSync=true`、`IgmpV3=false`、`UseNewProtocol=false`、`PreserveLegacyPresets=true`。历史固定序列只在完整匹配旧55/56配置时启用；D4的63/64始终按当前配置规划，旧预设入口也不会绕回D2。开关变化须对照现场程序，不根据包长猜测。

| 配置 | 映射序列 |
| --- | --- |
| Type1、无IGMP、同步裁剪 | `6102`组播映射 |
| Type1、无IGMP、非同步裁剪 | `6210`组播映射 |
| Type2、无IGMP | `6160`单播映射，输入类端口59993/60000 |
| Type3 | 同一节点依次`6102`、`6160`，不能打乱顺序 |
| Type1/2、IGMPv3 | `6120`60字节扩展帧，包含单播/组播和SendType |

先完整预检，再执行50节点清屏`61FF`→200ms间隔→映射→提交`61B8`→刷新`61B9`。节点之间有限并发，同节点严格顺序；未映射区域同样清除。失败不继续提交，不自动补偿或重放。

几何限定10列×5行、每节点1920×1080：4K输入的全屏源分片为384×432，半屏源分片为768×432。每个布局窗口独立Sign/Level，重复输入两侧不相互覆盖。协议C为行优先屏号，IP按列优先且146/147存在既有互换；A为布局窗口数，B为每窗累计分片序号，不能用IP索引或C替代B。

可选DES-ECB零填充外层`F1F2 + 长度 + 密文 + F3F4`仅为遗留设备兼容，默认关闭，不提供认证或现代安全保证。密钥由本地配置或`VideoWall__DesKeyHex`注入，禁止提交、回显或用于HTTP认证。无效密钥清屏前拒绝，不能把公开测试向量密钥用于现场。

自定义IP须在服务器`VideoWall:Inputs:<IP地址>`显式登记设备兼容流，包含单播/组播、端口、源尺寸和单播类端口；未登记时不能应用。普通RTSP/SRT通过窗口1/2播放器播放。非整除裁剪、异形/混尺寸墙、接缝补偿、特殊型号暂不支持。

## 接收与现场验收

TCP发送路径已接有界半包/粘包解析及内存诊断存储，处理`FCFD/6102`的22字节窗口回读和可选加密外层；同命令设备/板卡类型不误当窗口。校验和沿用原程序不验证的边界。仅被动读取短窗口内返回数据，不发送未经确认的查询触发，不把回读当ACK，不自动设置“已验证”。诊断仅在主机内存，不是持久布局状态或公开API。

本机包级、回环TCP、SQLite、HTTP、DOM和真实浏览器不替代现场抓包/出画。D4验收须记录开关和输入尺寸，使用标识画面逐项测试12组合及单侧清除，重点核对IP81、`2|1`、重复窗口ID、146/147与全墙连续裁剪，再恢复明确选定布局。电源独立，电视toggle保留，本功能不自动开关电源。原始依据见[逆向目录](protocols/simulator-video-joint/README.md)，本轮结果见[009验证](../specs/009-wall-input-mapping/verification.md)。
