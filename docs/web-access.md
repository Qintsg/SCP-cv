## 媒体与预设

媒体库先选目录，再按类型筛选；路径从`/`开始。媒体库上传进入当前目录，屏控上传进入根目录。普通上传原件保存到`DataRoot/media/<目录>/<实际文件名>`；同名文件自动采用新叶名，不覆盖原件。移动后实体路径和引用同步，播放或转换中的文件须先停止。旧日期结构不强行搬迁；已有记录如需调整，使用目录移动入口。

搜索可包含子目录，批量移动/删除按逐项结果显示，失败不自动重试。“打开到…”小卡片只选择窗口1/2；受理、等待输出和播放器确认分开。

预设目录独立于媒体目录，支持创建、改名、移动与空目录删除。高级配置折叠显示，空值保持。摄像机或声音绑定未知时，即使高级意图已保存，也会在任何激活动作前拒绝。

### 软件声音输出绑定（工作区接续，正式常驻尚未启用）

可信启动环境`SCP_CV_AUDIO_OUTPUT_DEVICE_ID`可指定完整Windows Render端点ID，覆盖两个Player的LibVLC、网页/共享、LibreOffice及AudioWorker。未配置不改变已有播放，但不能启用SCP-cv来源；已配置但端点无效、不唯一或不可用时拒绝默认回退。VLC创建与重播前核验并切换当前输出，播放初期保持实例静音，在五秒内确认原生端点后恢复请求静音；健康同源打开与暂停恢复不重置输出模块。观测发现输出不符时只停止该播放器的声音，不修改系统默认设备或总音量。

D4四个HDMI输出名称相同，不能按名字、枚举顺序或默认设备选择；已辨识的完整ID见[绑定记录](../specs/012-directory-camera-console/verification/device-bindings.md)。2026-10-13已在D4会话1对两个Player正式模块及Audio模块完成63/64各三轮播放/重播/关闭及缺失拒绝，未改变系统输出。当前正式012g只包含VLC可选配置且常驻未启用；下述网页/LibreOffice扩展尚未部署，不等于整个SCP-cv声音来源已接通或展厅可听。

工作区的网页/共享及LibreOffice也使用该端点配置，并额外要求可信`SCP_CV_PRIVATE_AUDIO_ENGINE_ROOT`。使用`runtime-dotnet/scripts/initialize-private-audio-engines.ps1`显式提供新Root、官方WebView版本目录和LibreOffice安装目录，脚本检查签名/空间/路径与逐文件摘要后生成双窗口副本，已有目录不覆盖。D4本轮已准备`D:/SCP-cv/runtime-dotnet/private-audio-engines-20261013`，但没有设置正式环境或激活。

## 共享质量

捕获不再设置1080P尺寸上限，请求不缩放原始像素；30fps、文字细节优先。发送建议上限为1080P 8Mbps、1440P 12Mbps、更高20Mbps。浏览器不支持参数时有界回退，不中断已有共享。诊断显示实际捕获/发送尺寸、帧率和按字节差分计算的码率；建议上限不等于实际码率。实际接收画面和双路5分钟稳定性仍需D4实体复测。
