# 网页访问与目录控制台（012）

D4目标入口是`http://192.168.5.194`（80）和`https://192.168.5.194`（443）。普通控制默认HTTP，不自动跳转。屏幕共享需HTTPS安全上下文：HTTP点击共享时先确认，再跳同主机同路径的HTTPS入口。现有用户自签证书保留；浏览器证书信任和站点许可仍需正常配置，程序不绕过TLS验证。

正式部署设置`VITE_FRONTEND_PORT=80`、`SCP_CV_HTTPS_PORT=443`；本地开发可用5173/5174。后端内部仍18444/18443，两种协议分别代理到同协议上游。AllowedOrigins必须包含无端口的HTTP/HTTPS现场地址。防火墙只放行这两个网页端口及现场网段，不关闭防火墙或撤销其它Node限制。

## 媒体与预设

媒体库先选目录，再按类型筛选；路径从`/`开始。媒体库上传进入当前目录，屏控上传进入根目录。普通上传原件保存到`DataRoot/media/<目录>/<实际文件名>`；同名文件自动采用新叶名，不覆盖原件。移动后实体路径和引用同步，播放或转换中的文件须先停止。旧日期结构不强行搬迁；已有记录如需调整，使用目录移动入口。

搜索可包含子目录，批量移动/删除按逐项结果显示，失败不自动重试。“打开到…”小卡片只选择窗口1/2；受理、等待输出和播放器确认分开。

预设目录独立于媒体目录，支持创建、改名、移动与空目录删除。高级配置折叠显示，空值保持。摄像机或声音绑定未知时，即使高级意图已保存，也会在任何激活动作前拒绝。

## 摄像机与现场声音

`/Camera`及六个系统项由后端保护，不可增删编辑移动。已确认五路：84后、85中1、86中2、87左、88右，RTSP路径均`/live/chn0`。固定监控已按用户最新更正及规划表“监控01”确认为`rtsp://192.168.5.76:554/live/chn0`；默认配置采用76，不使用89。仍可用可信`Venue:FixedCameraRtsp`覆盖（空字符串明确停用），重启后幂等同步。

摄像机输入节点不等于云台控制端点。运动、停止和位置预设尚未绑定，所以按钮不可用，直接调用API也被拒绝。规划表确认音频处理器为5.9、接5.10中控COM4；IN1/2为头戴话筒、IN3/4为手持话筒、IN5/6为分布式L/R。“头戴”不自动等于“悬挂”，设备族和控制帧仍须核验。IP81/SCP-cv来源路由及完整软件音频接线仍未完成；不能用电脑总音量冒充现场音量。

屏幕音频节点`192.168.5.155:4830`的6191读回与6190配置已接入，值0–100。先读取实际值再调整；写后读回不一致会明确报告，仿真结果单独标记。首页每次成功发送墙面布局后，当前屏幕音量重发一次；首次没有记忆值时先读实际值，不默认设100。墙面失败不发送音量；音量失败不自动重发墙面。

### 软件声音输出绑定（VLC模块已隔离实测，完整来源仍未接通）

可信启动环境`SCP_CV_AUDIO_OUTPUT_DEVICE_ID`可指定完整Windows Render端点ID，仅影响两个PlayerWorker的LibVLC资源与AudioWorker。未配置不改变已有播放；已配置但端点无效、不唯一或不可用时拒绝默认回退。创建与重播前核验并切换当前输出，播放初期保持实例静音，在五秒内确认原生端点后恢复请求静音；健康同源打开与暂停恢复不重置输出模块。观测发现输出不符时只停止该播放器的声音，不修改系统默认设备或总音量。

D4四个HDMI输出名称相同，不能按名字、枚举顺序或默认设备选择；已辨识的完整ID见[绑定记录](../specs/012-directory-camera-console/verification/device-bindings.md)。2026-10-13已在D4会话1对两个Player正式模块及Audio模块完成63/64各三轮播放/重播/关闭及缺失拒绝，未改变系统输出。正式来源切换仍禁用，网页共享/WebView2及LibreOffice不受此配置控制；隔离实测不等于整个SCP-cv声音来源已接通或展厅可听。

## 共享质量

捕获不再设置1080P尺寸上限，请求不缩放原始像素；30fps、文字细节优先。发送建议上限为1080P 8Mbps、1440P 12Mbps、更高20Mbps。浏览器不支持参数时有界回退，不中断已有共享。诊断显示实际捕获/发送尺寸、帧率和按字节差分计算的码率；建议上限不等于实际码率。实际接收画面和双路5分钟稳定性仍需D4实体复测。
