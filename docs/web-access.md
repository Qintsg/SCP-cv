# 网页访问与目录控制台（012）

D4 网页提供媒体目录、预案、摄像机和现场声音控制。当前系统、显示器及运行组状态见[维护文档](维护文档.md)。

D4的`http://192.168.5.194`（80）默认307跳转到`https://192.168.5.194`（443），保留页面路径和查询参数。登录、普通控制与屏幕共享均在HTTPS页面操作；未配置TLS的本机开发环境仍可使用HTTP。现有用户自签证书保留，浏览器证书信任和站点许可仍需正常配置。

正式部署设置`VITE_FRONTEND_PORT=80`、`SCP_CV_HTTPS_PORT=443`；本地开发可用5173/5174。后端内部仍18444/18443，两种协议分别代理到同协议上游。AllowedOrigins必须包含无端口的HTTP/HTTPS现场地址。防火墙只放行这两个网页端口及现场网段，不关闭防火墙或撤销其它Node限制。

## 媒体与预设

媒体库先选目录，再按类型筛选；路径从`/`开始。媒体库上传进入当前目录，屏控上传进入根目录。普通上传原件保存到`DataRoot/media/<目录>/<实际文件名>`；同名文件自动采用新叶名，不覆盖原件。移动后实体路径和引用同步，播放或转换中的文件须先停止。旧日期结构不强行搬迁；已有记录如需调整，使用目录移动入口。

搜索可包含子目录，批量移动/删除按逐项结果显示，失败不自动重试。“打开到…”小卡片只选择窗口1/2；受理、等待输出和播放器确认分开。

预设目录独立于媒体目录，支持创建、改名、移动与空目录删除。高级配置折叠显示，空值保持。摄像机或声音绑定未知时，即使高级意图已保存，也会在任何激活动作前拒绝。

## 摄像机与现场声音

`/Camera`及六个系统项由后端保护，不可增删编辑移动。已确认五路：84后、85中1、86中2、87左、88右，RTSP路径均`/live/chn0`。固定监控已按用户最新更正及规划表“监控01”确认为`rtsp://192.168.5.76:554/live/chn0`；默认配置采用76，不使用89。仍可用可信`Venue:FixedCameraRtsp`覆盖（空字符串明确停用），重启后幂等同步。

84–88 摄像机支持方向、变焦和六个预置位置。手控区按住运动，松开或失去焦点时停止；服务端租约超时也会释放。保存位置需要确认，实际机位以现场画面为准。

规划表确认音频处理器5.9接中控5.10 COM4；IN1/2头戴、IN3/4手持、IN5/6分布式L/R。用户明确确认“挂着的话筒”即头戴1/2，页面统一为“悬挂（头戴）话筒”，对应中控Join1；手持Join2、电脑音频Join3。百分比按原工程满量程19换算0–19共20档，显示请求值而非DSP读回，不能用电脑总音量冒充现场音量。

旧`hanging_volume`设置与预设仍可使用，保存/响应统一为`headset_volume`；同值两个别名仅发一次，不同值在任何设备动作前拒绝。预设编辑只保留一个话筒项，历史冲突会显示两值供修正。来源卡片可选择IP81或SCP-cv，点击“应用声音来源”发送；SCP-cv按主机实时就绪状态启用。页面显示最后发送的请求，实体路由以现场设备为准。

屏幕音频节点`192.168.5.155:4830`的6191读回与6190配置已接入，值0–100。先读取实际值再调整；写后读回不一致会明确报告，仿真结果单独标记。首页每次成功发送墙面布局后，当前屏幕音量重发一次；首次没有记忆值时先读实际值，不默认设100。墙面失败不发送音量；音量失败不自动重发墙面。

### 软件声音输出绑定

可信启动环境`SCP_CV_AUDIO_OUTPUT_DEVICE_ID`可指定完整Windows Render端点ID，覆盖两个Player的LibVLC、网页/共享、LibreOffice及AudioWorker。未配置不改变已有播放，但不能启用SCP-cv来源；已配置但端点无效、不唯一或不可用时拒绝默认回退。VLC创建与重播前核验并切换当前输出，播放初期保持实例静音，在五秒内确认原生端点后恢复请求静音；健康同源打开与暂停恢复不重置输出模块。观测发现输出不符时只停止该播放器的声音，不修改系统默认设备或总音量。

D4四个HDMI输出名称相同，应按设备接口身份确定端点。2026-10-27 驱动升级后，启动配置已更新为原输出对应的新端点；现场音源预检通过。维护记录见[维护文档](维护文档.md)。

网页、共享和LibreOffice使用同一端点配置，并要求可信`SCP_CV_PRIVATE_AUDIO_ENGINE_ROOT`。使用`runtime-dotnet/scripts/initialize-private-audio-engines.ps1`显式提供新Root、官方WebView版本目录和LibreOffice安装目录；脚本检查签名、空间、路径和文件摘要后生成双窗口副本。D4已配置`D:/SCP-cv/runtime-dotnet/private-audio-engines-20261013`。

LibreOffice每窗使用对应私有program目录；缺端点或错路径在原生启动前拒绝。用户内容前使用零音资源登记、绑定和核验WASAPI，暖机资源保留至实例关闭。控制或观测发现声音错路时静音自有会话并报错；转换任务不绑定声音。来源实体路由和现场扬声器效果需现场确认。

来源接口的软件就绪检查要求`SCP_CV_AUDIO_OUTPUT_DEVICE_ID`与可信`Venue:SoftwareAudioOutputDeviceId`一致，活动Render端点唯一，且两窗私有网页、LibreOffice文件和声音策略接口可用。D4启动配置使用升级后重新确认的端点。每次发送前检查这些条件；预案调用时同样检查。来源与中控请求显示发送状态，后续失败保留已写出的source和sent_fields。

网页实测已扩展至实际WPF PlayerRuntimeHost：D4双窗网页、缺引擎失败留旧、热切/保温重开静音旧页、切图片/关闭后无音及原生进程正常退出均通过，详见012接续验证；这不代替共享或完整运行组验证。

可信启动环境`SCP_CV_WEBVIEW_USER_DATA_ROOT`可指定当前安装的独立本地资料根目录。普通网页按`player-1`/`player-2`区分，共享按`screen-share/player-1`/`screen-share/player-2`区分，仍使用InPrivate随机分享profile。未配置保留原`LocalAppData/SCP-cv/WebView2`；显式相对/UNC/根盘/链接路径拒绝，不回退原资料。只允许管理员在启动环境设置，用户API和共享发布者不能传入目录。隔离验证运行组应使用全新目录，不复用正式服务资料；微软SDK的`WEBVIEW2_USER_DATA_FOLDER`覆盖会优先于代码路径，部署环境不要另设该覆盖项。

## 共享质量

捕获保留原始尺寸，30fps、文字细节优先。服务端下发发送策略，默认上限为1080P 16Mbps、1440P 24Mbps、更高48Mbps；捕获尺寸改变后同步档位。质量详情显示浏览器接受的上限、实际尺寸、帧率和码率。配置项见[屏幕共享文档](screen-sharing.md)。
