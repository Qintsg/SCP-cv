# UI交互约定

- 主要页面有一个页面标题、紧凑说明和主次动作；应用品牌不是每页内容标题。
- 路由path改变后主滚动归零、主内容获得可见可理解的键盘定位；同路由query/本地表单变化不重置编辑。
- 链接导航不发送播放/墙面/电源/音量/云台命令。首页窗口卡只进入对应窗口。
- 清除媒体筛选将类型设all、搜索设空，不移动目录、不重新上传或打开内容。
- 空目录说明如何添加；无匹配说明当前条件并提供清除入口；网络失败不作为空目录成功展示。
- 受理/写出/实际完成和未知保持区分；原确认、防重、禁用、权限与迟到响应规则不变。
- 小屏内容自然换行，主要动作至少44px；路径与长名称可换行或截断且完整值可访问；抽屉保留焦点与关闭规则。
