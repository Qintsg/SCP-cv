# Feature Specification: 紧凑仪表盘与品牌导航

**Feature Branch**: `main`（沿用当前工作区，不新建分支）

**Created**: 2026-10-20

**Status**: Implemented（仅本机，未推送／部署；后续服务端预览由018承接）

**Input**: 用户要求删除仪表盘“播放输出／选择窗口…”行及默认拖选提示，尽量让仪表盘与侧栏无需滚动；侧栏换色，Logo仅去外部白底并适配深色，点击品牌区回仪表盘；解释无需本机工具的直播预览可行性。仅本机，不部署，不使用 computer use。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 一屏完成现场概览 (Priority: P1)

操作者打开仪表盘，可看完四个窗口、布局预览、应用按钮及音量电源，无需先滚动查找操作。

**Why this priority**: 这是现场最常用页面，重复提示占用了布局操作的位置。

**Independent Test**: 在普通桌面及附件等效尺寸检查单屏、双屏和多矩形自定义布局；只读截图与几何检查，不连接现场。

**Acceptance Scenarios**:

1. **Given** 仪表盘正常状态，**When** 打开任意布局，**Then** 不出现两处指定删除的默认文字，常见桌面无需纵向滚动。
2. **Given** 空白自定义网格，**When** 框选或覆盖已有块，**Then** 有意义的已选范围或错误仍显示，预览比例保持32:9。
3. **Given** 短屏、手机或错误消息展开，**When** 内容超出，**Then** 允许滚动查看完整内容，不裁掉按钮或隐藏错误。

### User Story 2 - 清晰且可回首页的品牌导航 (Priority: P2)

操作者在不同主题下能辨认品牌，侧栏尽量完整呈现；点击顶部品牌区即可返回仪表盘。

**Why this priority**: 避免菜单与品牌混在底色中，并提供稳定的返回入口。

**Independent Test**: 浅色／深色、完整侧栏／折叠轨道分别截图；内存导航测试验证链接目标。

**Acceptance Scenarios**:

1. **Given** 两种主题，**When** 查看侧栏，**Then** 新底色与文字、图标和选中态可区分，Logo无外部白色方块，内部白色不误删。
2. **Given** 常见桌面高度，**When** 查看完整菜单，**Then** 无需侧栏滚动即可找到全部入口；更矮时仍可滚动访问设置。
3. **Given** 任意页面或折叠导航，**When** 激活品牌链接，**Then** 仅导航到仪表盘，不发送业务控制指令。

### User Story 3 - 理解网页预览的要求 (Priority: P2)

用户能区分D4实体播放与浏览器直播预览，并了解免安装预览需要什么流协议。

**Why this priority**: 避免误以为所有看网页的人都必须安装播放运行时。

**Independent Test**: 核查设置文案与使用文档；只读核对播放器官方支持范围。

**Acceptance Scenarios**:

1. **Given** 未启用可选预览，**When** 使用控制台，**Then** 能理解该状态不妨碍D4播放，不会因缺少工具被强制阻止控制。
2. **Given** 只有原始RTSP／RTMP地址，**When** 阅读免安装方案，**Then** 明确浏览器组件不能单独解决传输限制，必须有浏览器可读的设备流或网关；不把协议名中的RTMP编码支持误称原生RTMP连接。

### Edge Cases

- 超矮窗口、浏览器放大、超长源名称：保留滚动退路和省略显示，不使用隐藏溢出强装一屏。
- 预览连接失败／布局校验失败：保留就地错误，不影响应用门禁。
- 跟随系统深色与显式切换：品牌和菜单均跟随有效主题。
- 原图内部白色与外部白底：保留字孔及蓝框内部，不修改用户原图。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: MUST 删除窗口概览上方重复标题说明行和空网格默认拖选文字。
- **FR-002**: MUST 保留框选结果、重叠错误、可见焦点、32:9预览及应用操作；不得靠裁切或缩小到不可读来消除滚动。
- **FR-003**: SHOULD 在1440×900、1920×1080、2002×990和2560×1260桌面视口完整显示正常仪表盘和全部菜单；错误展开及更小窗口允许滚动。
- **FR-004**: MUST 更换侧栏底色，并让文字、图标、选中项和品牌在浅深主题下清楚可辨。
- **FR-005**: MUST 仅去除Logo外部白底，保留内部白色；深色可使用反色效果；原资源保持不变。
- **FR-006**: MUST 将整个顶部品牌区域变为返回仪表盘的可访问链接，折叠模式同样可用。
- **FR-007**: MUST 澄清实体播放、普通网页视频和可选RTSP／RTMP预览各自的依赖，并如实说明免安装方案的传输前提。
- **FR-008**: MUST 仅本机实现与验收，不推送、部署、连接D4或执行实体操作；浏览器仅只读检查，不模拟输入。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 指定4档桌面视口、浅深主题、正常单屏／双屏／自定义布局中，仪表盘及菜单滚动高度不超过可见高度1像素；不存在横向溢出。
- **SC-002**: 两处默认说明出现次数为0；选择反馈及错误回归检查通过；品牌入口目标始终为仪表盘。
- **SC-003**: 浅深主题品牌、菜单正常文字对比度至少4.5:1，Logo在两种底色均可辨认，外部透明、内部白色验证通过。
- **SC-004**: 本地验收无页面／控制台错误，物理设备调用、远端部署和浏览器输入模拟次数均为0。

## Assumptions

- 这是016完成后的界面收紧，不更改播放、布局协议、预案持久化或预览架构。
- “尽量不滚动”不要求所有手机／任意矮屏强行一屏，不牺牲阅读与错误可达性。
- 用户询问播放器可行性；本轮调研并解释，不擅自把“本机直拉”改为D4转发。
- 字体与Ant组件沿用项目，不引入新的收费资源。
