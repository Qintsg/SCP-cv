# Feature Specification: 屏幕共享连接与折叠入口

**Feature Branch**: `main`
**Created**: 2026-11-05
**Status**: Draft
**Input**: 用户选择共享内容后无法出画；改善折叠入口；D4 仅通过 10.88.50.194 连接，不使用 computer use。

## User Scenarios & Testing

### User Story 1 - 找到并展开共享控制 (Priority: P1)

操作者在窗口控制页面可以辨认共享折叠栏，展开、收起后继续管理同一共享。

**Independent Test**: 实际浏览器检查折叠和展开布局、箭头方向、键盘焦点及窄窗口可见性。

**Acceptance Scenarios**:
1. **Given** 窗口控制页，**When** 查看收起的共享入口，**Then** 有清晰边框、背景和箭头。
2. **Given** 正在共享，**When** 收起控制栏或切换页面，**Then** 原有共享继续。
3. **Given** 支持共享的桌面浏览器窗口变窄，**When** 查看控制页，**Then** 仍可找到共享入口。

### User Story 2 - 选择内容后建立共享 (Priority: P1)

操作者授权共享后，可以在目标窗口收到画面；失败时能够识别实际故障环节。

**Independent Test**: 检查 D4 会话和最近失败命令，在本机使用真实媒体、信令和接收资源复测已定位故障。

**Acceptance Scenarios**:
1. **Given** 有效授权及在线播放器，**When** 连接成功，**Then** 实际视频帧到达后显示共享中。
2. **Given** 共享建立失败，**When** 查看错误，**Then** 提供对应故障反馈，不能声明已经出画。

### Edge Cases

- 收起面板、页面导航和尺寸变化不得重新采集或终止原共享。
- HTTPS、浏览器采集能力和身份认证条件仍需满足。
- D4 旧会话已经清理时，不推测其停止原因；记录可取得的实际证据。

## Requirements

### Functional Requirements

- **FR-001**: 共享入口必须有可辨认的整栏样式和随展开状态变化的箭头。
- **FR-002**: 共享入口支持原生键盘操作及可见焦点，桌面窄窗口保持可见。
- **FR-003**: 折叠操作必须保持已有采集、连接和共享所有者。
- **FR-004**: 连接修复须根据可复现故障或实际失败证据进行；连接成功状态须以实际帧为依据。
- **FR-005**: 诊断信息不得包含凭据、接收授权或完整协商内容。
- **FR-006**: 远端检查只连接 10.88.50.194；验证使用命令行及只读无头浏览器。
- **FR-007**: 发布端和接收端必须支持主机配置的标准地址发现或中继服务，以便组网环境建立可达的真实候选；不得修改协商内容伪造地址。

### Key Entities

- 共享所有者：绑定账号、主机、窗口及采集寿命。
- 共享会话：协商、接收帧和关闭状态；延续已有身份规则。

## Success Criteria

- **SC-001**: 桌面、Pad 和窄窗口的共享入口具有可见的箭头、边框及焦点。
- **SC-002**: 展开、收起和切换视图不增加共享连接或采集次数。
- **SC-003**: 已定位故障完成真实回归验证，明确记录 D4 与本机验证边界。

## Assumptions

- 本轮包含本地修复、真实跨机验证和 D4 服务修复；不重新打包客户端。
- 现场暂未共享时，使用最近失败命令和操作者重试信息建立证据。
