# 功能规范：网页侧栏与客户端玻璃导航

**Feature Branch**: `main`

**Created**: 2026-10-30

**Status**: Implemented

**Input**: 网页使用左侧菜单，修复Pad竖屏底栏触摸位置，完善液态玻璃；完成后提交推送并更新桌面打包。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 网页保持左侧导航（Priority: P1）

普通网页使用左侧菜单，触摸屏和窄视口也保留网页导航形式。

**Independent Test**: 在手机、Pad和桌面尺寸打开Web构建，检查左侧菜单与底栏的实际可见状态。

**Acceptance Scenarios**:

1. **Given** 普通网页，**When** 调整宽度或旋转触摸设备，**Then** 左侧菜单保持可用，悬浮底栏不存在。
2. **Given** 安卓手机或Pad客户端，**When** 打开横屏或竖屏页面，**Then** 保留悬浮玻璃底栏及相应内容留白。
3. **Given** Windows客户端，**When** 查看页面，**Then** 使用桌面侧栏。

### User Story 2 - Pad准确选择并呈现玻璃效果（Priority: P1）

操作员在Pad竖屏或旋转后触摸底栏，可以准确选择入口；拖动镜片连续移动，松手仅导航一次。

**Independent Test**: 读取真实底栏及入口位置，检查每个入口中心、边界、旋转和显示比例变化对应的选择；运行生产运动接口并检查玻璃图像。

**Acceptance Scenarios**:

1. **Given** Pad从横屏转为竖屏且底栏宽度不变，**When** 触摸五个入口，**Then** 每个入口命中准确。
2. **Given** 正在拖动镜片，**When** 旋转、取消或卸载页面，**Then** 旧手势取消，不导航到旧位置。
3. **Given** 深浅色页面，**When** 查看及按压底栏，**Then** 玻璃具有背景折射、边缘高光和连续形变，图标清晰。
4. **Given** 系统启用减弱动态或减弱透明效果，**When** 使用底栏，**Then** 相应效果减弱且功能保持。

### User Story 3 - 更新源码与桌面制品（Priority: P1）

验证后将本轮及030未提交内容提交到两个现有仓库，更新桌面Windows便携ZIP、Android手机APK及Pad APK。

**Independent Test**: 核对两远端提交、Windows包内容、APK版本及签名、包内网页摘要和桌面文件。

**Acceptance Scenarios**:

1. **Given** 修改与本机验证完成，**When** 提交推送，**Then** 两个仓库均包含相同提交及规范。
2. **Given** 新制品，**When** 检查桌面文件，**Then** Windows便携包和两种安卓命名包均更新，已有用户配置与签名保持。

### Edge Cases

- 视口变化没有改变底栏宽度时，命中位置仍须更新。
- 镜片形变和视差不得改变交互命中区域。
- 菜单变化保留手机精简模式与Pad预览，避免改变媒体业务规则。
- 打包使用现有证书与签名，口令及密钥保持本机存储。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 普通Web和Windows客户端使用左侧导航。
- **FR-002**: 安卓手机与Pad保留悬浮底栏，Pad支持横竖屏。
- **FR-003**: 底栏触摸按当前显示坐标命中，支持位置变化与显示比例变化。
- **FR-004**: 拖动期间不切页面，松手只执行一次选择，取消或旋转不提交旧手势。
- **FR-005**: 玻璃材质改善折射、高光、形变和文字清晰度，保留系统偏好支持。
- **FR-006**: 保留030工作区功能并同步文档、测试及依赖声明。
- **FR-007**: 提交并正常推送两个仓库，更新桌面Windows便携ZIP及两个arm64-v8a APK名称。
- **FR-008**: 本轮不更新D4服务或操作现场设备。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Web三档宽度及触摸条件均显示侧栏，Android手机与Pad四种方向/尺寸显示底栏，无水平溢出。
- **SC-002**: 五个入口的中心及两侧内部位置，在横竖屏和位置变化后全部正确命中。
- **SC-003**: 连续运动、取消、重复选择、卸载和系统偏好通过实际生产接口验证。
- **SC-004**: 两远端提交一致，三个桌面制品存在且内容校验通过，安卓升级版本及原签名一致。

## Assumptions

- 手机和Pad使用现有同一自适应安卓应用，分别输出两个文件名。
- 本机验证继续遵守不使用computer use、不模拟鼠标键盘的约束；真实手指验收与几何验证分别记录。
