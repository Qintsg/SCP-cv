# Feature Specification: 维护菜单隐藏与显示播放器窗口

**Feature Branch**: `main`
**Created**: 2026-10-29
**Status**: Implemented
**Input**: Web右上角维护菜单按窗口当前状态显示隐藏窗口或显示窗口，使管理员可以操作输出显示器上的其他窗口；本轮不打包客户端。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 隐藏与恢复输出窗口 (Priority: P1)

管理员使用维护菜单，将窗口1和窗口2放到其他窗口后方，操作显示器上的其他程序；操作完成后恢复两个输出窗口置顶显示。

**Why this priority**: 释放管理员对输出显示器的操作空间，同时保留当前播放。
**Independent Test**: 在本机真实窗口检查窗口顺序、播放状态、窗口身份、位置和尺寸。

**Acceptance Scenarios**:

1. **Given** 两个输出窗口置顶，**When** 选择隐藏窗口，**Then** 两个窗口取消置顶并位于其他窗口后方，菜单随后提供显示窗口。
2. **Given** 已隐藏窗口，**When** 选择显示窗口，**Then** 相同输出窗口恢复置顶，原位置、尺寸及播放内容保留。
3. **Given** 隐藏中的窗口，**When** 换源或重新设置其显示位置，**Then** 继续保持隐藏状态。

### User Story 2 - 根据实际状态操作 (Priority: P1)

维护菜单只根据实际窗口观测切换文字。处理中阻止重复提交，失败反馈使用现有通知。

**Why this priority**: 管理员需要清楚窗口是否真正恢复。
**Independent Test**: 真实HTTP、命令队列、窗口进程观测及Web渲染验证。

**Acceptance Scenarios**:

1. **Given** 状态已确认，**When** 点击操作，**Then** 请求受理期间保持原状态，执行完成后更新文字。
2. **Given** 播放器离线或状态未知，**When** 打开维护菜单，**Then** 该选项不可操作。
3. **Given** 两个窗口状态不一致，**When** 打开菜单，**Then** 提供显示窗口，将两者恢复置顶。

### User Story 3 - 发布与桌面启动 (Priority: P2)

管理员从D4桌面启动已部署的网页和播放器。启动完成后自动结束，重复启动保留已有播放；失败时可以看到原因及启动日志。

**Why this priority**: 便于现场使用新的维护功能。
**Independent Test**: 核对桌面快捷方式并执行对应入口，比较启动前后的进程身份、播放及输出配置。

**Acceptance Scenarios**:

1. **Given** 已部署服务，**When** 运行桌面入口，**Then** 检查网页及两播放器就绪后自动结束。
2. **Given** 已有运行服务，**When** 再次运行入口，**Then** 保留进程身份及播放。
3. **Given** 启动配置缺失，**When** 检查入口，**Then** 非零退出并提供清楚的中文原因。

### Edge Cases

- 媒体换源不取消待执行的窗口隐藏请求。
- 旧实例、旧所有者、缓存结果与晚到观测不得覆盖新窗口状态。
- 运行组重新启动时，新窗口按正常置顶启动，初始状态重新观测。
- 普通网页、屏幕共享、演示文稿、图片和视频使用同一窗口维护能力。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: MUST 在Web右上维护菜单添加隐藏窗口／显示窗口单个动态选项，统一控制输出窗口1和2。
- **FR-002**: MUST 隐藏时将窗口放在其他窗口后方，恢复时置顶，并保持窗口身份、播放、音频、位置、尺寸及系统显示模式。
- **FR-003**: MUST 保持隐藏状态通过换源和位置调整；重启后的新窗口正常置顶。
- **FR-004**: MUST 通过实际状态切换菜单，未知或离线禁用，处理中防止重复提交，失败提供现有错误反馈。
- **FR-005**: MUST 保留命令认证、所有者及观测顺序约束；媒体操作不得取消窗口维护意图。
- **FR-006**: MUST 完成真实本机窗口、HTTP及Web验证并更新文档；不打包客户端。
- **FR-007**: MUST 提交并推送两个仓库，部署D4网页与播放运行时，保留原有媒体、播放设置和显示配置，并在部署后验证窗口隐藏与恢复。
- **FR-008**: MUST 优化D4桌面一键启动，使用后台快捷方式，成功后自动结束；重复点击复用运行服务，失败时提示原因并保留日志。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 连续20轮隐藏与显示后，相同窗口及媒体资源保留，窗口顺序与菜单状态一致。
- **SC-002**: 隐藏期间换源及位置调整后仍保持隐藏，两个窗口的位置及尺寸不变。
- **SC-003**: 旧实例、旧所有者及旧观测序列均无法改变最新窗口状态；媒体代次过期不影响有效窗口观测。
- **SC-004**: 请求受理不提前改变菜单操作，真实执行后更新；离线与未知状态不可提交。
- **SC-005**: D4两窗在线、原来源恢复、媒体原件摘要和显示配置保持，隐藏与显示均取得实际窗口观测。

## Assumptions

- 隐藏表示取消置顶并将输出窗口放在其他窗口后面；播放器继续运行。
- 本轮只交付Web入口及其必要的主机运行时支持，不生成Windows或Android控制客户端安装包。
