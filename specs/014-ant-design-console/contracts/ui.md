# UI与既有API合同

## 大屏布局

读取使用既有GET；点击应用捕获参数后PUT预检，检查返回draft.can_apply和明确修订，再调用按修订POST应用。身份变化、不可应用、失败或冲突均不继续/重试，不增加后台自动发送。

用户可见：单/双屏、区域输入、布局选项、一个应用按钮及必要错误。不可见：保存草稿、草稿徽标、发送状态/详情、上次发送布局。短提示不得称实体画面已确认。音量重发仍经runtime store原链路。

## 组件迁移

- 业务操作仍调用既有store/API；组件不接触数据库或设备。
- 菜单只由选中事件执行一次，禁用/隐藏项无法派发。
- 危险确认、原目录与选中身份冻结不变。
- 滑杆、复选、开关、表单和Tab的Ant事件映射须有真实DOM回归。
- Web/App共享组件/路由，不保留Naive版本。
