# Feature Specification: 带凭据的直播源

**Feature Branch**: `main`
**Created**: 2026-10-20
**Status**: Completed（本机实现和验证，未推送/部署）
**Input**: 支持直接粘贴带用户名和密码的RTSP等直播地址。真实设备凭据不写入文档/测试。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 登记、编辑并打开认证直播 (Priority: P1)

人员粘贴`rtsp://用户名:密码@主机:端口/路径`即可保存并打开；修改只影响下次打开。

**Why this priority**: 当前拒绝内嵌凭据，导致认证摄像机不能使用。
**Independent Test**: 虚构凭据的创建、读取、编辑和播放器实际认证；不用真实设备。
**Acceptance Scenarios**:

1. **Given** 合法认证地址，**When** 新增/编辑，**Then** 凭据、端口、路径、转义和查询保留，状态仍为待验证。
2. **Given** 已保存源，**When** 打开，**Then** 播放器能够使用凭据认证；认证失败不假报出画。
3. **Given** 旧无凭据源、组播或SRT，**When** 保存/播放，**Then** 既有语义保持，非法协议明确拒绝。

### User Story 2 - 默认隐藏凭据 (Priority: P1)

仅明确编辑/查看时显示完整地址，普通摘要、自动名称和日志不泄漏凭据。

**Why this priority**: 认证能力不能把密码带到常规界面。
**Independent Test**: 正反对照输入、自动名称、播放摘要与诊断，播放仍使用原地址。
**Acceptance Scenarios**:

1. **Given** 认证地址未填名称，**When** 保存，**Then** 自动名称/路径不含凭据或敏感查询值。
2. **Given** 播放摘要或结构化日志，**When** 展示地址，**Then** 目标可识别但凭据不可见，播放地址不被脱敏值覆盖。
3. **Given** 新增/编辑流，**When** 填写地址，**Then** 默认隐藏、可明确查看，有特殊字符转义说明。

### Edge Cases

- 百分号编码的`@`、`:`、`#`、空格，IPv6/端口/路径/查询不重复编码。
- 空用户名配密码、非法协议/控制字符拒绝，不回显密码；UDP空userinfo组播保持。
- SRT使用自己的查询参数，不新增用户名/密码语义；内置摄像机保护和匿名拒绝保持。

## Requirements *(mandatory)*

- **FR-001**: 新增与编辑统一接受RTSP、HTTP(S)、RTMP直播的内嵌用户名/密码。
- **FR-002**: 保存至播放器的完整地址保持，保存不表示已连通。
- **FR-003**: 非法输入及不支持的认证格式拒绝；旧SRT/UDP/RTP语义保持。
- **FR-004**: 自动名称/路径、普通播放摘要和结构化日志不暴露凭据及敏感查询值。
- **FR-005**: 地址输入默认隐藏、可查看，说明格式与特殊字符编码，编辑不保存脱敏占位符。
- **FR-006**: 更新文档/合同；验证仅虚构凭据与回环，不操作用户示例设备。

### Key Entities

- 直播地址：目标及可选凭据，供授权编辑和播放。
- 地址展示值：仅供查看，不得用于保存或认证。

## Success Criteria *(mandatory)*

- **SC-001**: 认证地址创建、修改、重读和实际认证链路通过，旧源回归通过。
- **SC-002**: 常规摘要、自动名称和结构化日志中虚构秘密出现0次，实际认证仍正确。
- **SC-003**: 默认隐藏/显式查看及转义提示可用；无效输入不创建或改动记录。

## Assumptions

- 沿用可信操作员权限和受管存储，不新增凭据库、密钥或数据迁移；授权URI合同保留完整地址，不声称对已登录用户保密。
- HTTP(S)仅指媒体流，不扩展网页源登录；不部署/重启D4，原实体待验项保持。
