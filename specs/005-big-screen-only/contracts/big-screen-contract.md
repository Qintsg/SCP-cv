# 对外合同增量

正式机器可读合同以 `docs/openapi.yaml` 及其 `$ref` 文件为准，本文件记录设计意图。

| 能力 | 合同变化 | 失败语义 |
| --- | --- | --- |
| 会话与显控 | 有效 `window_id` 仅 1、2；旧 3、4 操作不得入队 | 4xx + 明确错误码，状态不变 |
| 显示器 | 两块可选大屏输出附稳定设备名/角色；其他显示器仅诊断 | 非允许目标拒绝，不能自动回退 |
| 大屏布局 | 新增读取、保存/预览、原子应用布局；两个固定预设映射旧 `single/double` | 未知帧布局应用返回 `protocol_unavailable`，不发包、不修改 active |
| 预案 | 新写入只接受 1、2；历史有效 3、4 目标在所有副作用前拒绝 | `scenario_legacy_window`，保留原记录 |
| PPT 源 | 上传后可查询逐页图片准备状态、页数与错误；播放会话报告实际模式 | 转换失败可重试，不能返回可播放成功 |
| PPT 实验开关 | 服务端 GET/PATCH，默认 false，跨控制端一致 | 未启用时原生放映请求拒绝；既有会话不隐式切换 |
| 文件夹与媒体 | 上传、文件/文件夹移动或重命名使逻辑位置与物理路径一致 | 重名不覆盖；移动失败显式报错并补偿 |
| 设备电源 | `splice_screen`、`tv_left`、`tv_right` 维持原合同 | 电视仍为只写 toggle，不能声称确认开关状态 |

旧 `/api/runtime/` 的 `single/double` 操作暂保留为两个固定预设的兼容入口，前端新布局界面以统一的活动布局回执为准。手动布局具体帧字段待现场抓包后单独补充合同与测试。
