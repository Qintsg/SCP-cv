# T013网页音频与真实内容链路（2026-10-11）

## 实现边界

正式共享面板接入独立音频控制器和紧凑声音区。实际属性、设置草稿和操作反馈分开；默认接收静音，无本地/接收音轨或实际后帧时禁用并说明原因。未知状态只允许先静音，切换静音不顺带应用未提交的音量草稿。

一次操作只发一个本人认证PATCH，不调用普通VLC音量。202仅受理；精确命令ID、目标、名称和原OPEN代次必须匹配，completed/ok之后仍须本人分享实际volume/muted同时匹配才确认。八秒包括所有IO，超时不自动重发；停止、页面/账号/主机寿命结束立即取消，音频失败不终止有效视频。

普通轮询与音频回读共用递增请求序号；较晚结果已接受后，较早在途成功或失败不能覆盖它。此序号仅防客户端倒序，服务端原Worker、提交版本和实际帧门禁仍独立保留。
