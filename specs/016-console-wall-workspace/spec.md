# Feature Specification: 4K与目录化现场控制工作区

**Feature Branch**: `main`（沿用当前分支）
**Created**: 2026-10-20
**Status**: Draft
**Input**: 用户十二张标注截图、4K适配、50格布局/短码、本机直播预览、目录与预案编辑。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 大屏可视化编排 (Priority: P1)

操作员选择单屏、双屏或自定义，看到32:9画面；自定义模式在50格上框选不重叠矩形，指定输入，修改/删除，使用可解析短码交换布局，最后明确应用。

**Why this priority**: 核心现场操作，避免误发与假成功。
**Independent Test**: 本机验证框选、重叠拒绝、编辑、短码往返和一次应用，不连接实体。
**Acceptance Scenarios**:

1. **Given** 10列5行空网格，**When** 框选矩形并选来源，**Then** 变为可预览显示块，不能重复框选覆盖，点块可改源/删除。
2. **Given** 多块布局，**When** 修改或输入代码，**Then** 代码实时更新/还原完整布局，不查数据库、不自动发实体帧。
3. **Given** 非法代码、重叠、预留窗口或未知映射，**When** 应用，**Then** 明确拒绝，无部分发送。
4. **Given** 单/双屏，**When** 选来源，**Then** 选择器在32:9预览上方，无额外保存草稿步骤、布局选项与旧发送详情。

### User Story 2 - 本机预览与4K (Priority: P1)

显示四张窗口卡片，1/2可控制，3/4仅前端预留；本机能拉流则预览，不能则内联说明。

**Why this priority**: 看清内容且不增加D4代理负担。
**Independent Test**: 预览生命周期、请求路径及静默失败检查；4K输入裁切回归。
**Acceptance Scenarios**:

1. **Given** 输入地址，**When** 小卡/大预览加载，**Then** 用户本机拉chn1/chn0，不经过D4。
2. **Given** 不可拉流，**When** 失败，**Then** 只显示状态及下一小行脱敏原因，无弹窗；无配置则无错误。
3. **Given** 窗口3/4页面，**When** 浏览，**Then** 明确预留无控制，不新增原生窗口。
4. **Given** 用户已手动将D4输出改4K，**When** 播放与编排，**Then** 窗口1/2输入尺寸3840×2160，IP81维持独立1080P，不修改系统。

### User Story 3 - 目录化媒体与可编辑预案 (Priority: P1)

目录和文件同表呈现，媒体播放状态独立列；预案同样管理，明确编辑入口，保存为可维护文件。

**Why this priority**: 减少重复信息和操作成本。
**Independent Test**: 目录导航/搜索/批量、预案新建编辑保存再读取。
**Acceptance Scenarios**:

1. **Given** 目录内有媒体和子目录，**When** 查看，**Then** 同表行显示文件夹图标、名称、类型文件夹、大小横线，无重复目录卡片/媒体路径行/副标题。
2. **Given** 已保存预案，**When** 编辑保存重读，**Then** 设置无丢失，目录可输入路径联想，文件为YAML。
3. **Given** 预案布局选择，**When** 编辑，**Then** 有窗口1全屏、窗口1左窗口2右、高级编辑器，高级存布局码。
4. **Given** 高级项，**When** 摄像机填0/空，**Then** 保持；音量填0为0%，空才保持。

### User Story 4 - 紧凑一致的页面 (Priority: P2)

修复图标文字错位、背景音乐播放控件、设置冗余与侧栏Logo。

**Why this priority**: 长时间现场使用清晰可靠。
**Independent Test**: 桌面/手机/4K截图对照和组件回归。
**Acceptance Scenarios**:

1. **Given** 背景音乐桌面页，**When** 浏览，**Then** 播放按钮/开关正常尺寸，进度/时间对齐，列表内滚动，尽量无整页滚动。
2. **Given** 设置，**When** 查看，**Then** 维护工具取代重复布局/系统音量，可重启运行组/重置窗口/重连SSE，保留危险确认；开发信息不再窄长分栏。
3. **Given** 侧栏，**When** 查看，**Then** 指定AILAB Logo、窗口3/4入口、设置下沉，删“多媒体显示控制”。

### Edge Cases

- 逆向拖选、跨已有块、取消、键盘与触摸；非法/过长/损坏/未知版本代码、非法IP。
- 流凭据不进短码、DOM错误和日志；用户本机服务缺失/断开不回退D4代理。
- 切主机/登出/离页后旧请求不可接续发送；3/4不能成为原生控制目标。
- 不覆盖旧媒体文件；旧预案保持态不得静默变成切墙；音量0不能被当保持。
- 本机验证不能代替D4真实4K出画及现场协议验收。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 10×5、32:9、不重叠矩形多块编辑及明确应用。
- **FR-002**: 确定性字母数字代码，含版本/损坏检测，无数据库映射，常见1–4块简短。
- **FR-003**: 保留确认IP81及已验证单/双屏；未知实体映射禁发，不虚构协议。
- **FR-004**: D4窗口1/2输入3840×2160，IP81仍1080P，不改系统分辨率。
- **FR-005**: 四窗口卡片/导航，3/4明确预留不可控，不新增原生播放器。
- **FR-006**: 小预览chn1、大预览chn0，只本机拉流，错误仅内联一行，无流不报错。
- **FR-007**: 媒体/目录同表、状态独立列，保留过滤搜索移动保护批量，删除标红信息。
- **FR-008**: 预案同表、可编辑、目录路径联想及YAML文件保存重读。
- **FR-009**: 预案布局预设/高级复用布局规则与代码；机位0/空保持，音量0有效。
- **FR-010**: 修复Ant对齐、紧凑音频页、维护入口和诊断布局。
- **FR-011**: 指定Logo、侧栏设置下沉、删指定说明，手机44px目标/键盘/减弱动效有效。
- **FR-012**: 同步合同/文档/验证；不推送部署、不连D4、不做实体控制。

### Key Entities

- **布局块**: 不重叠网格矩形与输入。
- **布局码**: 无凭据完整布局的可解析紧凑表示。
- **本机预览**: 无流/准备/播放/不可用/失败及脱敏原因。
- **预案文件**: 名称、目录、窗口、布局码、音量、摄像机配置。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 1–50块合法布局往返一致；非法/重叠输入全部拒绝且无发送。
- **SC-002**: 预览失败无弹窗，无流零错误，零D4预览代理请求。
- **SC-003**: 目录/批量/编辑回归通过，预案保存再读取设置无丢失。
- **SC-004**: 1440、2560、3840桌面及390手机主要操作无裁切，画面32:9，对齐正常。
- **SC-005**: 自动验证无新增错误，如实记录未测的D4实体4K/流/映射。

## Assumptions

- 50格沿用墙面10列5行；截图一处IP84按已确认上下文采用IP81。
- 浏览器不原生播放RTSP/RTMP；若用本机辅助明确安装条件，不支持时只内联不可用。
- 任意多IP信息不能无限压缩，代码不承诺固定长度；常见布局优先短，密集布局完整无损。
- 新预案默认窗口1全屏，旧预案的保持语义必须保留，不能静默切墙。
- 本轮保持不部署、不启停D4；窗口3/4与未知映射需后续证据才启用实体控制。
