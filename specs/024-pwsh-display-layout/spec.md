# Feature Specification: PowerShell 7与D4横向显示排列

**Feature Branch**: `main`
**Created**: 2026-10-22
**Status**: 本轮维护及启动验证完成
**Input**: 改用PowerShell 7，显示器按1–2–3–4–5从左到右横向排列，显示器2–5保持4K；完成后启动CV测试，通过10.88.50.194连接D4。

## User Scenarios & Testing

### User Story 1 - 使用新版脚本环境（Priority: P1）

维护者在D4使用项目维护与启动入口时，明确使用PowerShell 7，保持当前媒体、服务状态与原系统工具。

**Why this priority**: 避免旧诊断序列化引发的资源耗尽，明确后续维护入口。
**Independent Test**: 实际查询安装版本、执行有限的小文本序列化及解析当前项目脚本，检查桌面和计划任务入口，不启动CV。
**Acceptance Scenarios**:
1. 官方程序完整性通过后，实际版本为7，指定项目入口使用该程序。
2. 环境或模块不兼容时明确停止，原系统工具和CV媒体保持。
3. 安装及入口调整不运行CV启动脚本、不触发项目计划任务。
4. 完成显示维护后，使用迁移后的项目入口启动CV并检查后端、两个播放器和网页；保持原媒体与音量配置。

### User Story 2 - 五个显示器依次排列（Priority: P1）

操作者从控制显示器1向右移动，依次经过显示器2、3、4、5，五个显示器顶部位于同一水平位置。

**Why this priority**: 符合现场输出的实际使用顺序。
**Independent Test**: 在原交互会话读取并核对五个实际桌面矩形、输出信号及63–66主组播输入尺寸。
**Acceptance Scenarios**:
1. 显示器1保持主显示器和1920×1200，位置为0,0。
2. 显示器2–5保持3840×2160，位置依次为1920,0、5760,0、9600,0、13440,0，无重叠或空隙。
3. 只进行本次明确的位置维护，不创建后台分辨率重设任务，不修改墙面、电视、音源、电源或摄像机。

### Edge Cases

- SSH会话不能读取交互桌面；操作必须在原登录会话中执行，使用隐藏且有时间限制的单次维护任务。
- 显示器缺失、设备路径或主显示器身份变化、4K信号不匹配时，首个修改前拒绝执行。
- 系统拒绝配置或验证未生效时明确失败，不通过重试常驻写入掩盖问题。
- 用户在维护期间改变显示配置时，重新核对实际身份与状态，不使用陈旧编号推断。

## Requirements

### Functional Requirements

- **FR-001**: MUST 通过官方可信制品安装可运行的PowerShell 7，记录版本及完整性证据，不替换系统powershell.exe或全局SSH默认程序。
- **FR-002**: MUST 将本项目当前启动、桌面与计划任务入口明确指向新版程序；保持参数、账号、权限、触发器和媒体配置。
- **FR-003**: MUST 在显示维护期间保持CV未启动；完成显示读回后按用户授权启动CV测试，核对旧组残余身份及退出，保持媒体、声音与无关进程。
- **FR-004**: MUST 将五个已确认的显示器按1至5横向排列，保持显示器1属性，显示器2–5桌面及信号均为4K。
- **FR-005**: MUST 在实际交互会话验证位置和信号，完成后清理本次临时维护任务与进程。
- **FR-006**: MUST 对维护过程设置时间与资源边界，记录实际错误、退出和最终状态，不使用模拟资源作为现场通过证据。

### Key Entities

- 显示目标：当前GDI编号、设备路径、坐标、桌面尺寸、信号尺寸、主显示器及刷新率。
- 项目脚本入口：已安装程序路径、脚本路径、参数、调用方式及现存运行状态。
- 维护记录：基线、目标、实际结果、进程退出与临时任务清理证明。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 指定项目入口全部明确使用已核验的7版本程序，真实小文本处理在有限预算内完成。
- **SC-002**: 五个实际矩形按编号依次相接，顶部Y均为0；2–5桌面与信号均3840×2160，63–66回读一致。
- **SC-003**: 显示维护期间没有新增CV核心进程；后续启动测试取得唯一ControlHost、Supervisor、两个PlayerWorker及其真实在线状态，网页可访问，显示排列仍保持。
- **SC-004**: 临时维护任务及其进程全部清理，没有新增自动分辨率设置机制，原媒体和应用配置保持。

## Assumptions

- 用户授权本轮安装新版PowerShell及进行一次显示排列维护；不重启Windows、不修改驱动或EDID。
- 显示器1继续使用1920×1200；2–5保持已有4K刷新时序，不主动改变刷新率、缩放或旋转。
- 仅迁移项目使用的脚本入口，不修改Windows全局默认Shell；既有网页等残余进程不因入口变更重新启动。
- 普通网页缓存问题和既有分辨率回退根因仍由独立调查承接，本轮不扩大业务修复范围。
- 用户于2026-10-23授权完成环境与显示维护后启动CV测试，并使用10.88网段管理地址；不发送墙面、电视、电源或云台控制命令。
