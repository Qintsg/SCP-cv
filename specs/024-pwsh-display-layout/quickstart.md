# 验证指南

前置条件：D4原交互会话保持登录，用户已授权安装PowerShell7及单次显示位置维护；显示维护结束后启动CV测试。

1. 核对官方ZIP、Microsoft签名、实际版本、CIM/ScheduledTasks、小文本序列化及脚本解析。
2. 查看桌面CMD和release任务，确认绝对pwsh路径及原参数；核对startup.json摘要，只调用CheckOnly/NoPause。
3. 单次隐藏维护读取五屏身份和模式，再维护位置。读回1至5依次相接、顶部Y=0；1仍主显示1920×1200，2至5桌面/信号均4K。
4. 既有611A工具只读查询63–66，核对主组播及5000端口、实际4K。
5. 核对没有新增ControlHost、Supervisor或PlayerWorker；临时任务及进程清理完成，没有常驻显示设置机制。
6. 核对旧组残余进程身份和实际退出，再使用新版入口启动CV；核验后端、两窗及网页，复查五屏位置及4K。

实际命令、时间、证据和边界记入verification.md；脚本解析不作为未来完整播放验收。
