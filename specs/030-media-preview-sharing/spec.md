# 功能规范：媒体预览、网页刷新与持续共享

**Feature Branch**: `main`

**Created**: 2026-10-30
**Status**: Implemented
**Input**: 网页源支持刷新以读取新数据；共享切换标签后保持连接；点击媒体可预览所有类型。完成后不提交、不推送、不部署。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 刷新播出的网页（Priority: P1）

操作员在窗口控制中刷新当前网页，读取最新页面资源。

**Independent Test**: 使用带长缓存的真实本机网页，更新正文后执行刷新，检查实际播出内容和完成结果。

**Acceptance Scenarios**:

1. **Given** 网页已打开且资源有缓存，**When** 点击刷新，**Then** 当前窗口重新请求页面并显示最新正文。
2. **Given** 当前来源为其它类型或播放器离线，**When** 查看刷新入口，**Then** 控件不可用；其它类型的网页刷新请求明确失败，不改变其它内容。

### User Story 2 - 切换页面时持续共享（Priority: P1）

操作员开始共享后，可以切换控制台页面、窗口控制标签和浏览器标签，继续发送同一共享画面。

**Independent Test**: 真实采集和接收连接保持期间切换控制视图，检查连接身份、后续帧和停止后的资源释放。

**Acceptance Scenarios**:

1. **Given** 窗口1正在共享，**When** 离开控制页面再返回，**Then** 保持原采集和连接，可继续停止及调节声音。
2. **Given** 正在共享，**When** 切换浏览器标签后返回，**Then** 共享保持，短暂连接中断允许原连接恢复。
3. **Given** 正在共享，**When** 停止、关闭页面、退出账号或切换主机，**Then** 释放原采集和连接，旧结果不能建立新共享。
4. **Given** 在其它控制台页面，**When** 有活动共享，**Then** 提供紧凑停止入口，并明确对应窗口。

### User Story 3 - 点击媒体预览（Priority: P1）

操作员点击媒体名称打开预览，在控制端查看图片、视频、音频、网页、文稿和直播源，保持现场播放内容。

**Independent Test**: 使用实际文件和本机流服务逐类打开预览，检查内容、文稿翻页、失败状态和关闭后的释放。

**Acceptance Scenarios**:

1. **Given** 媒体列表存在各类来源，**When** 点击名称，**Then** 打开对应预览且不替换播出窗口。
2. **Given** 文稿已转换，**When** 打开并翻页，**Then** 呈现对应真实页图；未准备时可明确发起准备并读取完成结果。
3. **Given** 登记的直播源，**When** 打开预览，**Then** 按需复用现有预览连接；关闭后释放引用。
4. **Given** 不可达、浏览器不支持或禁止嵌入的来源，**When** 打开预览，**Then** 在固定区域显示简短反馈，保留其它操作。

### Edge Cases

- 预览期间删除来源、切换主机或账号，旧预览必须关闭并释放。
- 连续选择不同文件时，较早请求不得覆盖当前预览。
- 含凭据直播源复用服务端登记身份，页面不展示凭据。
- 手机仍可显式打开媒体预览；仪表盘自动预览的手机限制保持。
- 刷新保留网页账号、来源地址及窗口几何；页面自身离线或数据接口报错照实呈现。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 网页刷新必须实际重新加载并绕过浏览器页面资源缓存，报告完成或失败。
- **FR-002**: 刷新仅作用于当前网页来源，不使用播放成功状态代替刷新完成。
- **FR-003**: 共享寿命属于当前控制端账号与主机，控制视图切换不停止采集。
- **FR-004**: 页面退出、账号失效、切换主机和用户停止必须释放共享资源。
- **FR-005**: 短暂连接状态变化保留原连接的恢复机会，永久失败明确停止。
- **FR-006**: 所有已支持的媒体类型具有名称点击预览入口，包括流媒体、PPT及PDF。
- **FR-007**: 预览只在明确打开时加载，关闭后释放媒体、计时器和流引用。
- **FR-008**: 预览适配手机、Pad和桌面，文稿可翻页，视频与音频可控制播放。
- **FR-009**: 发布按031授权执行源码提交、双仓推送及客户端打包，D4部署排除。

### Key Entities

- **活动共享**：目标窗口、当前账号及主机、采集资源、连接、实际接收状态。
- **媒体预览**：当前来源身份、类型、准备状态、页码、加载及失败状态。
- **网页刷新命令**：目标窗口、来源代次、执行结果。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 长缓存本机网页更新后，显式刷新可读取最新正文，完成状态与实际导航一致。
- **SC-002**: 同次共享跨控制视图切换至少10次，连接身份保持且持续获得后续帧。
- **SC-003**: 图片、视频、音频、网页、PPT、PDF和直播源各有真实内容验证；关闭后相关自有资源释放。
- **SC-004**: 三档屏幕尺寸的预览没有水平溢出；加载与错误不造成控制按钮大幅位移。

## Assumptions

- 刷新由操作员明确触发，不强制修改第三方网页的数据轮询策略。
- 网页嵌入遵守原站限制；外部网页可在新标签查看。
- 本机测试使用独立数据目录与进程，不连接D4。
