# 检查与验证

## 调查范围

仓库中共有 184 个受版本控制的前端 Vue/TypeScript 文件、355 个后端 C# 文件和 58 个文档 Markdown 文件。通过文本与引用搜索确定候选，再检查控制台文案、认证、大屏布局、文稿预览、退役接口及使用文档的相关调用。前端 86 个文件包含限定或状态相关词语；这一数字包含必要状态、注释和合法错误提示，不代表问题数量。

本轮确认并处理两项影响操作的行为：首次认证探测的连接失败被当成未登录；有效墙面布局中的空白地址被前端拒绝且恢复异常被隐藏。认证、请求归属、墙面预检、设备控制、媒体路径和资源释放检查继续生效。

精简 11 处页面提示，删除 15 个未使用的旧界面文案键；整理使用文档及三个相关专题文档。清理两个没有调用方的退役转换/探测实现及探测器独占的 HTTP 客户端注册，保留历史 IPC 响应及数据库模型。

文稿单页预览在每次请求中检查全部页图，大文稿存在重复读取。现有合同要求其他页损坏时整份预览不可用；未找到能可靠反映外部文件变化的简单失效机制，因此维持完整性检查。旧 PowerPointHost 仍有独立测试和项目引用，本轮保留。

## 实际验证

- .NET SDK 10.0.400 下 Release 全解决方案构建成功，0 警告、0 错误。
- 前端 `npm --prefix frontend run typecheck`、`build:web` 和 `build:app` 通过。
- `ScpCv.Domain.Tests` 的大屏布局和布局代码测试通过 13 项。
- `frontend/scripts/verify-auth-wall-real.mjs` 启动本机真实 Hardware ControlHost，验证连接失败、服务启动后的未登录状态与前端布局地址校验；自有服务已退出。
- 本机真实 ControlHost 接受并读取含空白地址的双屏布局；只保存布局，没有应用设备映射。
- 只读无头浏览器检查离线提示、未登录页面和真实认证后的设置页面，页面无未捕获脚本异常；截图保存在 `.validation/clarity-026/`。
- 本轮没有模拟鼠标键盘，因此页面重试按钮和自定义网格的交互未通过浏览器执行；没有连接 D4 或测试实体设备。
- Spec Kit 校验和 `git diff --check` 通过。
