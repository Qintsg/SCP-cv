# 行为合同

文稿导航：动态文稿的上一步、下一步分别发送PREVIOUS_EFFECT/NEXT_EFFECT；静态文稿使用PREV/NEXT。保留末页无操作和实际命令反馈。

滑块：同次拖动输入已排队或提交的最终值在结束时不重复提交；独立新操作仍可以提交相同值。

共享快照增加video_policy对象，包含full_hd_bitrate、qhd_bitrate、ultra_hd_bitrate和max_frame_rate。接收端保持原协议；旧服务没有该字段时客户端采用默认策略。

手机：用户页面不创建非必要的直播预览订阅及媒体缩略图；墙面矩形编辑与控制功能保留。

Pad：使用独立于手机精简规则的触摸导航状态，保留预览。横竖屏只调整布局，不重置当前来源；底部内容留白覆盖玻璃底栏与系统安全区。文稿保留当前页、下一页和备注。
