87的原错误为`Failed reading RTSP data: Error number -138 occurred`和`Invalid data found when processing input`。进一步在同样五秒读取预算下比较85/87：两者OPTIONS均200；85的DESCRIBE取得731字节/200，87的DESCRIBE连接成功但五秒内收到0字节而超时。因此问题已定位到SDP描述获取阶段，实际设备/上游原因仍未确定；没有改URI、盲目重启设备或放宽验收。

音频处理器5.9的TCP80/443/5062均未连通；这不推断UDP5062能力或DSP实际增益。仅本机Windows窗口清单未发现D4或项目可操作窗口，普通网页媒体真实点击及人工桌面捕获仍不能用脚本播放/合成canvas代替。
